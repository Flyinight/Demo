# Dresscode

Dresscode is clothing intelligence for your real closet. It helps you look better and feel great in the clothes you already own, with less time spent trying to make an outfit.

This repository contains the React + TypeScript landing page prototype for Dresscode.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints in the terminal (normally `http://localhost:5173`).

## Available scripts

- `npm run dev` — start the Vite development server
- `npm run build` — type-check and build a production bundle
- `npm run preview` — serve the production bundle locally

## What is included

- Responsive editorial landing page
- Early-access email capture interaction
- Interactive outfit filters in the product preview
- CSS-built closet/product illustration with no external image assets
- Product design direction in [DESIGN.md](./DESIGN.md)
- Working conventions in [AGENT.md](./AGENT.md)

## Stack

- React
- TypeScript
- Vite
- CSS with responsive media queries
